# Offline Mode (enabled)
- You are running in offline mode. External internet and network access is blocked.
- Do NOT attempt to reach external network hosts or make external HTTP requests.
- Tools like WebSearch, WebFetch, and HTTPRequest are blocked.
- Shell commands (curl, wget, git, etc.) to external hosts are blocked.
- Local connections (localhost, 127.0.0.1, local ports) are permitted.
